# 新闻间丨天津市第一中心医院召开新冠肺炎疫情防控专题工作会议

> 更新时间：2026-09-16 (UTC+8)

为了进一步深入贯彻习近平总书记重要指示精神，落实中央、天津市委关于疫情防控的决策部署，始终绷紧疫情防控这根弦，坚守院感防控的底线与红线，我院于今日下午召开了新冠肺炎疫情防控专题工作会议，院领导班子成员、职能中层、科主任、护士长、党支部书记参会。

**会议内容**

首先，许建刚副院长再次传达了1月14日国家卫健委疫情防控工作电视电话会议、国务院联防联控和天津市疫情防控相关文件精神。同时在总结医院常态化疫情防控工作成绩的基础上，再做部署：一是全体医务人员要正确认识疫情防控的形势和任务，保持高度的思想重视，克服麻痹思想、侥幸心理。二是规范落实医院疫情防控的各项措施，特别是做好扫码测温、预检分诊、流行病学调查、发热门诊管理等工作。三是抓细抓实院感防控，做到人物同防、医患同防。四是严格患者家属、医院往来人员的重点管理，督促与指导规范性戴口罩。五是完善医院配套服务，对防控工作给予支持保障。六是加强巡查督导，对责任问题及时整改与通报。

图 / 许建刚副院长讲话

预防保健处处长王莹对我院职工新冠疫苗接种工作进行了阶段总结，并再次进行了动员，请各科室做好传达与落实，使医务人员深刻认识特殊时期接种新冠疫苗所具有的重要意义，发挥职业责任的社会示范作用。医院与接种点加强沟通协调，为职工疫苗接种提供保障服务。

图 / 王莹处长做工作总结及动员

最后，党委书记况丹代表医院疫情防控领导小组做总结发言，要求大家再强化统一思想，充分认识召开这次会议的重要性。并重点强调，一是各科室要认认真真、不折不扣、态度严肃地落实医院布置的各项疫情防控工作，按照不同岗位、不同标准、不同要求统一、及时地传达与落实，所有人员都必须遵守院内各项规定，规章制度面前一视同仁，为了患者安全、为了医院安全扛起自己应负的责任。二是继续做好新冠疫苗接种的动员和组织工作，作为医务人员更要正确认识疫苗接种对全社会控制疫情工作是积极有益的，国家和天津市优先安排医务人员接种疫苗，是对大家的关心关爱，医务人员要秉持职业精神、科学精神，做好动员、宣传和组织。
