# 【培训】首期急危重症培训正式开始啦！

> 更新时间：2026-09-16 (UTC+8)

2022年3月12日，经过前期精心筹备，由我院主办的第一届汕头市急危重症超声精英培训班如期举行，给潮汕三市**17名**精英学员们带来了一场急危重症超声的饕餮盛宴。

培训班由我院急诊重症监护室（EICU）负责人陈永如主持，陈永松院长为培训班致辞，对培训导师团队及学员们表示热烈欢迎，介绍了我院致力于高水平医院建设，重视发展高端医疗技术及智慧医疗服务，将促进医疗科技与临床诊疗互为依托，推动数字医疗的发展，在医疗、科研、教学等领域取得新的突破，希望学员们通过此次培训班能有所收获，有所提高。

北京协和医院急诊科副主任徐军教授通过现场视频连线致辞，随着急危重症技术的高速发展，如何减少区域差异，使医疗技术均质化，急危重症超声规范化培训尤为重要。海南医学院第二附属医院急诊科张秋彬博士通过简明扼要的PPT和生动有趣的讲解，每章节理论课（超声基础知识、e-FAST、血管超声及超声引导穿刺等）后随即安排分组练习，由培训导师和助教团队现场解疑答惑，手把手教学，学员们学习热情高涨，最后一致通过培训考核，陈永如代表主办方为每位学员颁发培训证书。

我院急诊科陈英杰主任进行了总结，此次培训班高度重视疫情防控，做好周全准备。培训班的成功举办，离不开医院的重视和社会的支持，我院急危重症培训基地将继续以急危重症生命支持技术为中心，全面铺开院内、院外的学习共享和培训工作，进一步推动急危重症的专科建设和人才培养，促进医联体单位、跨区域医院单位间的共同进步。
