# 新手爸妈必存！产后康复护理清单，让妈妈少受苦、宝宝更健康！

> 更新时间：2026-09-16 (UTC+8)

**

亲爱的宝爸宝妈：

恭喜你们喜迎新生命！在享受喜悦的同时，别忘悉心呵护刚分娩的妈妈。产后恢复分阶段、有重点，这份清单将陪您顺利度过特殊时期。

第一阶段：****住院期间（产后1-3天）**

**安心休养打基础**

**宝妈护理要点**

**好好休息：**尽量与宝宝同步休息，接待访客交给家人。

**观察恶露：**初期为红色，会逐渐变淡变少。若1小时湿透卫生巾或流大血块，立即告知护士。

**护理伤口：**顺产妈妈每日清洗会阴，勤换卫生用品；剖宫产妈妈保持腹部伤口敷料干燥，咳嗽大笑时轻按伤口减痛。

**及时排尿：**产后2-4小时尝试自行排尿，防尿潴留，困难时及时求助。

**尽早活动：**体力允许时尽早下床慢走，助恢复、防血栓。

**母乳喂养起步：**做好“早接触、早吸吮、早开奶”，学习正确哺乳姿势（含住大部分乳晕），按需喂养。

**宝爸/家人行动清单****

主动分担访客接待，创造安静休息环境；协助妈妈如厕、活动，补充温水；准备清淡易消化的产后餐。

第二阶段：出院后1-2周

适应生活建节奏

宝妈护理要点

以卧床休息为主，逐步增加活动量，不急于做家务。

饮食均衡清淡，多喝汤水、蔬果防便秘，无需“大补”。

奶水不足时让宝宝多吸吮，保证睡眠水分；警惕情绪低落、易怒等产后抑郁信号，及时就医。

宝爸/家人行动清单

多倾听妈妈感受，说“我能为你做什么”；共同学习宝宝护理，成为育儿合伙人。

第三阶段：产后3-5周

恢复加速早规划

宝妈护理要点

练凯格尔运动（助盆底肌恢复、改善漏尿）和腹式呼吸，避免跑步、跳跃等剧烈运动。

重视产后避孕：即使母乳喂养、月经未恢复，仍可能排卵怀孕。

宝宝小睡时做喜欢的事，享受“自我时间”。

宝爸/家人行动清单

主动带宝宝1-2小时，让妈妈出门或小聚；提醒鼓励妈妈做康复运动，可一起参与；共同商量避孕计划，安排宝宝满月体检和疫苗接种。

第四阶段：产后42天及以后

全面评估迎常态

宝妈护理要点

核心任务：产后42天复查

这是“毕业大考”，妈妈需查体重、血压、伤口、子宫恢复、盆底功能等，一定要参加！

温馨提示**

产后恢复不是妈妈一个人的事，而是一家人的“新项目”。家人的理解、支持和主动分担，是妈妈身心康复的最佳“良药”。请把这份清单记在心上，互相提醒，共同携手，开启充满爱与欢笑的新篇章！
